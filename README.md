# on-device-motion-anomaly
on-device-motion-anomaly using the xiao ML kit



Slightly different than  https://github.com/webmcu-ai/on-device-motion  which has 3 classes which you could change to more classes.  This firmware has two classes

0Still  where the motor or machine is off 
1Normal where the motor or machine is running at it's normal operating temperature and in good working condition and the device is
attached in a standard oriented set direction with good connectivity
